# spaxcr API Parameters

This page documents the main public functions exposed by `spaxcr`.

```python
import spaxcr
```

## Navigation

- [Project Overview](./index.md)
- [Tutorial](./tutorial.md)

## Common Conventions

- `adata`: an `AnnData` object generated by `spaxcr.pp.load_xcr` and usually enriched with coordinates by `spaxcr.pp.addloc`.
- `chain`: one chain or isotype. Supported values are usually `TRA`, `TRB`, `IGH`, `IGK`, `IGL`, and in selected functions `IGHA`, `IGHG`, `IGHM`, `IGHD`, `IGHE`.
- `focus_cdr3=False`: analyze clone IDs.
- `focus_cdr3=True`: merge clones with the same CDR3 and analyze CDR3 sequences.
- `basis="spatial"`: use `adata.obsm["spatial"]` as the coordinate matrix.
- `ax`: a matplotlib `Axes` object. If supplied, the function draws into the existing axis.
- `save`: output path for a figure. If `None`, the figure is not saved.

## Preprocessing API: `spaxcr.pp`

### `spaxcr.pp.load_xcr`

```python
spaxcr.pp.load_xcr(
    clone_file,
    cloneId_barcode_file,
    focus_functional_clone=True,
    focus_chain=None,
    from_mixcr=True,
    add_mutation=True,
)
```

Build an immune repertoire `AnnData` object from a clone table and a clone-barcode table.

Parameters:

- `clone_file`: path to the clone table. For MiXCR output, spaxcr parses MiXCR-specific fields. For custom tables, the file must contain at least `cloneId`, `topChains`, and `aaSeqCDR3`.
- `cloneId_barcode_file`: path to a tab-separated, headerless table with either `barcode, cloneId` or `barcode, cloneId, count`.
- `focus_functional_clone`: if `True`, remove non-functional CDR3 sequences containing `*` or `_`.
- `focus_chain`: receptor type filter. Use `None` to keep all supported chains, `"TCR"` to keep `TRA/TRB`, or `"BCR"` to keep `IGH/IGK/IGL`.
- `from_mixcr`: set to `True` for MiXCR output; set to `False` for a custom clone table.
- `add_mutation`: whether to add mutation metadata. In MiXCR mode, mutation fields are extracted from MiXCR alignment columns. In custom mode, the clone table must already contain `V_align`, `J_align`, `nSeqCDR3`, and `mutation_status`.

Returns:

- A new `AnnData` object with clone metadata in `adata.var` and clone information in `adata.uns["immu_repertoire"]["clone_info"]`.

Notes:

- Numeric clone IDs are converted to `clone_<id>`, for example `700` becomes `clone_700`.
- If MiXCR output lacks `topChains`, spaxcr infers chains from `allVHitsWithScore`.

### `spaxcr.pp.addloc`

```python
spaxcr.pp.addloc(adata, loc_info, basis="spatial")
```

Add spatial coordinates to an immune repertoire `AnnData` object.

Parameters:

- `adata`: input `AnnData`.
- `loc_info`: `pandas.DataFrame` with barcode index and required columns `x` and `y`.
- `basis`: key used to store coordinates in `adata.obsm[basis]`.

Returns:

- A new `AnnData` object ordered by `loc_info.index`.

Notes:

- Spots/cells present in `loc_info` but missing from the clone matrix are added with zero clone counts.
- The function writes `x`, `y`, and `obsm[basis]`.

### `spaxcr.pp.filter_clone`

```python
spaxcr.pp.filter_clone(
    adata,
    min_cdr3_length=1,
    max_cdr3_length=30,
    min_cells=1,
    min_count=1,
    count_column=None,
)
```

Filter clones by CDR3 length, count, and number of detected spots/cells.

Parameters:

- `adata`: input `AnnData`.
- `min_cdr3_length`: minimum allowed CDR3 amino acid length.
- `max_cdr3_length`: maximum allowed CDR3 amino acid length.
- `min_cells`: minimum number of spots/cells in which a clone must appear.
- `min_count`: minimum clone-level count.
- `count_column`: column in `clone_info` used for `min_count`. If omitted, spaxcr searches for a count-like column.

Returns:

- A filtered `AnnData` object.

## Analysis API: `spaxcr.tl`

### `spaxcr.tl.query`

```python
spaxcr.tl.query(
    adata,
    var_names=None,
    obs_names=None,
    obs_chain=None,
    focus_cdr3=False,
    cdr3_names=None,
    cdr3_isotype=None,
    flatten=False,
    dedup=True,
    remove_na=False,
    reverse=False,
)
```

Query the relationship between clones/CDR3 sequences and spots/cells.

Parameters:

- `adata`: input `AnnData`.
- `var_names`: clone ID or list of clone IDs. Returns the spots/cells where these clones are detected.
- `obs_names`: spot/cell name or list of names. Returns clones or CDR3 sequences detected in these spots/cells.
- `obs_chain`: chain or isotype filter used with `obs_names`, for example `IGH`, `TRA`, or `IGHA`.
- `focus_cdr3`: when querying `obs_names`, return CDR3 sequences instead of clone IDs.
- `cdr3_names`: CDR3 sequence or list of CDR3 sequences. Returns the spots/cells where these CDR3s are detected.
- `cdr3_isotype`: isotype filter used with `cdr3_names`.
- `flatten`: if `True`, merge dictionary values into a single list.
- `dedup`: if `flatten=True`, remove duplicated values.
- `remove_na`: remove keys whose result list is empty.
- `reverse`: when querying clone IDs or CDR3s, reverse the mapping from `{query: cells}` to `{cell: query_items}`.

Returns:

- A dictionary by default, or a list when `flatten=True`.

### `spaxcr.tl.expansion`

```python
spaxcr.tl.expansion(
    adata,
    chain=None,
    focus_cdr3=False,
    groups=1,
    labels=["Notexpansion", "Expansion"],
    show_match_dict=True,
)
```

Classify clones or CDR3 sequences by the number of spots/cells in which they appear.

Parameters:

- `adata`: input `AnnData`.
- `chain`: chain or isotype filter. If `None`, all chains are used.
- `focus_cdr3`: analyze CDR3 sequences instead of clone IDs.
- `groups`: expansion thresholds. An integer creates two groups, `<=groups` and `>groups`. A list or tuple such as `(1, 10)` creates multiple intervals.
- `labels`: names assigned to expansion groups. The number of labels must match the number of generated intervals.
- `show_match_dict`: print the interval-to-label mapping.

Returns:

- A `DataFrame` containing ID, chain/isotype, `n_cells`, and expansion `group`.

### `spaxcr.tl.intersection`

```python
spaxcr.tl.intersection(
    adata,
    groupby,
    chain=None,
    focus_cdr3=False,
    groups=None,
    mode="outer",
)
```

Compute clone or CDR3 overlap across groups.

Parameters:

- `adata`: input `AnnData`.
- `groupby`: column in `adata.obs` used for grouping.
- `chain`: optional chain or isotype filter.
- `focus_cdr3`: analyze CDR3 sequences instead of clone IDs.
- `groups`: subset of groups to compare. If `None`, all groups are used.
- `mode`: intersection mode. Use `"outer"` for group-specific IDs, `"inner"` for IDs shared by all groups, or `"total"` to report all group combinations.

Returns:

- A `DataFrame` with ID and occurrence information.

### `spaxcr.tl.smooth`

```python
spaxcr.tl.smooth(
    adata,
    obs_name,
    alpha=1,
    kernel="Gaussian",
    smooth_distance=None,
    min_round_spot=1,
    fillna=False,
    basis="spatial",
    include_self=True,
    add_obs="smooth",
    denoise=False,
    denoise_k=10,
    denoise_cutoffmode="mean",
    norm_by=None,
)
```

Spatially smooth a numeric column in `adata.obs`.

Parameters:

- `adata`: input `AnnData` with spatial coordinates.
- `obs_name`: numeric observation column to smooth.
- `alpha`: distance decay parameter exposed by the API.
- `kernel`: distance decay kernel. Supported values include `Gaussian`, `Exponential`, `Laplacian`, `Cauchy`, `distance`, and `distance2`.
- `smooth_distance`: search radius for neighboring spots/cells. If `None`, spaxcr estimates a radius from the minimum spot distance.
- `min_round_spot`: minimum number of neighbors required to keep a smoothed value.
- `fillna`: if `True`, fill missing input values with zero before smoothing.
- `basis`: coordinate basis in `adata.obsm`.
- `include_self`: include the current spot/cell in its own neighborhood.
- `add_obs`: output column name in `adata.obs`.
- `denoise`: whether to run a KNN-based denoising step before smoothing.
- `denoise_k`: number of neighbors for denoising.
- `denoise_cutoffmode`: denoising threshold mode, such as `mean`, `median`, or `p50`.
- `norm_by`: optional observation column used to normalize neighborhood totals.

Returns:

- `None`. The function writes results to `adata.obs[add_obs]`.

### `spaxcr.tl.density`

```python
spaxcr.tl.density(
    adata,
    clones=None,
    cdr3s=None,
    chain=None,
    consider_umi=False,
    density_name="density",
    smooth_density=False,
    smooth_alpha=1,
    smooth_distance=None,
    norm_by=None,
    result_norm=None,
)
```

Compute clone, CDR3, or chain density per spot/cell.

Parameters:

- `adata`: input `AnnData`.
- `clones`: clone ID or list of clone IDs.
- `cdr3s`: CDR3 sequence or list of CDR3 sequences.
- `chain`: chain or isotype filter.
- `consider_umi`: if `False`, count detected clone entries; if `True`, sum matrix counts/UMIs.
- `density_name`: output column name in `adata.obs`.
- `smooth_density`: whether to smooth the density result.
- `smooth_alpha`: smoothing alpha parameter.
- `smooth_distance`: smoothing radius.
- `norm_by`: optional observation column used to normalize smoothed values.
- `result_norm`: if truthy, rescale the final density to 0-1.

Returns:

- `None`. The function writes results to `adata.obs[density_name]`.

### `spaxcr.tl.spatial_pairing`

```python
spaxcr.tl.spatial_pairing(
    df_a,
    df_b,
    r=5,
    n_perm=1000,
    random_state=None,
    n_jobs=-1,
    chunksize=None,
    progress_desc="Permutation test",
    stat=True,
    min_observed=0,
)
```

Test spatial pairing between two sets of named coordinates.

Parameters:

- `df_a`: `DataFrame` with columns `name`, `x`, and `y`.
- `df_b`: `DataFrame` with columns `name`, `x`, and `y`.
- `r`: spatial radius used to define a nearby pair.
- `n_perm`: number of permutations for the null model.
- `random_state`: random seed.
- `n_jobs`: number of worker processes. `-1` uses all CPUs.
- `chunksize`: multiprocessing chunk size.
- `progress_desc`: progress bar label.
- `stat`: if `True`, run permutation testing; if `False`, return observed pair counts only.
- `min_observed`: remove pairs with fewer observed contacts than this value.

Returns:

- A `DataFrame` with columns such as `name_a`, `name_b`, `observed`, `expected`, `std`, `p_value`, `z_score`, `n_a`, `n_b`, and `adjust_p`.

- `chunksize`: multiprocessing chunk size.
